When creating issue/task documents:
- Write in **Bahasa Indonesia**
- Keep descriptions **high-level** — no source code snippets in the issue
- Structure with numbered steps for junior devs or AI agents
- Include instructions to use **Context7** for best practice references
- Use markdown with clear headers and checklists

**Why:** User delegates bug fixes via issue docs as specifications.
**How to apply:** Default to this format for issue docs, plans, or task breakdowns.
